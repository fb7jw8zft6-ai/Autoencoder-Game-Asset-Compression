🎮 Game Asset Autoencoder

Deep Learning Based Image Compression and Reconstruction

📘 Project Information

This project demonstrates an autoencoder-based approach for compressing and reconstructing virtual game asset images while attempting to preserve their visual information.

🎯 Project Objective

To create an autoencoder that reduces the representation size of virtual in-game assets while reconstructing the visual content.

📁 Dataset

The project uses a synthetic game-asset image dataset containing four categories:

  • Character
  • Vehicle
  • Weapon
  • Environment

Total images: 600

🧹 Preprocessing

  • Images converted to RGB.
  • Images resized to 64 × 64 pixels.
  • Images converted to tensors.
  • 80% training and 20% testing split.

⚙️ Training Configuration

  • Framework: PyTorch
  • Optimizer: Adam
  • Learning rate: 0.001
  • Loss function: MSE
  • Batch size: 32

🧠 Model Architecture

The project uses a convolutional autoencoder. The encoder progressively reduces the spatial dimensions of the input image and produces a latent representation. The decoder then reconstructs the image from this representation.

💡 Architecture Explanation

The encoder contains three convolutional layers. Each layer uses a stride of 2, which reduces the spatial dimensions of the feature maps.

The final encoder output has the shape 128 × 8 × 8. This is the latent representation used by the decoder.

The decoder uses three transposed convolution layers to progressively increase the spatial dimensions back to 64 × 64.

The final decoder layer uses a Sigmoid activation so that the reconstructed pixel values remain in the 0–1 range.

🔎 Result Analysis

The trained autoencoder successfully learns to encode 64 × 64 RGB game asset images into a latent representation and reconstruct the images using the decoder.

The quantized latent representation contains 8,192 8-bit values compared with 12,288 values in the raw 64 × 64 RGB representation. This gives a raw representation ratio of approximately 1.50 ×.

The example quantized reconstruction produced an MSE of approximately 0.005649 and a PSNR of approximately 22.48 dB.

Some visual blur can be observed in the reconstructed images. This is a current limitation of the trained model and dataset.

The 1.50 × value represents a raw latent representation ratio rather than a final compressed-file ratio, because actual file storage would also involve metadata and other storage overhead.

Evaluation Metrics

MSE: Measures the reconstruction error between the original and reconstructed images.

PSNR: Measures reconstruction quality. Higher PSNR generally indicates lower reconstruction error.

Compression Ratio: Compares the raw RGB representation with the quantized latent representation.
